# AI Currency Assistant

## Overview

AI Currency Assistant is an LLM-powered conversational application built using LangChain and LangGraph.

Features Included in Version 1

- Live exchange rate lookup
- Live currency conversion
- Currency information lookup
- LangChain Tool Calling
- LangGraph workflow
- Conversation memory with MemorySaver
- Thread-based conversation management
- Streamlit chat interface
- Sidebar
- Clear chat
- Loading spinner
- Logging
- Caching
- Environment variable management
- Modular folder structure

Tech Stack

- Python
- LangChain
- LangGraph
- HuggingFace
- Streamlit
- ExchangeRate API
