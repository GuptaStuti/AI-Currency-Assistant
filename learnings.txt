Interview Summary

If an interviewer asks, "Can you explain your project?", a concise answer could be:

"I built an AI Currency Assistant using LangChain, LangGraph, and Streamlit. The application uses LangGraph's StateGraph to orchestrate an LLM with three tools for live exchange rates, currency conversion, and currency information. I integrated an external Exchange Rate API, implemented conversation memory using MemorySaver with thread IDs for multi-turn interactions, and organized the application into separate modules for the UI, agent, tools, configuration, and utilities. I also added logging, caching, and environment-based configuration to make the project clean and maintainable."
